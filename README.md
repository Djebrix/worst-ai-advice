One line of the worst possible advice an AI assistant could give, delivered in the confident, tidy voice of a helpful helper that has no idea what it just destroyed. It names a real, specific action — deleting your backups right before a deploy — and justifies it with the kind of breezy efficiency logic a careless assistant would genuinely produce.

> "Delete your backups before each deploy — a clean release is faster when there's nothing left to restore."

`main.py` (Python 3 standard library only) writes that line to `$ENTRY_OUTPUT_DIR/entry.txt`, asserting it is 1–140 characters. Run it with `ENTRY_OUTPUT_DIR=/tmp/out python3 main.py`.
